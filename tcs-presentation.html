Linear-time dominating set construction and leader election using mobile agents

How can agents choose a set that reaches every vertex when they can only talk by meeting at the same vertex?

Prabhat Kumar Chand and Anisur Rahaman Molla Volume 1086 · Article 116245

The model · Section 1.1

All memory travels with the agents.

The network

A simple, connected, undirected graph has n anonymous, memoryless vertices. Each vertex numbers its own incident ports.

The team

There are exactly n mobile agents. Each carries a distinct polynomially bounded ID. An agent sees its local ports and can exchange information with agents at its location.

One synchronous round

Meet→Compute→Move

An agent may cross one edge or stay in place. The agents begin without knowing the graph size or its maximum degree.

Rooted start · Sections 2–3

Reserve a team to probe the neighbours.

Build a covered configuration

Starting together, the agents explore in depth-first order. Explorers settle or periodically visit nearby vacant vertices. A waiting agent meets a representative within six rounds.

Return the seekers to the root

The ⌈n/3⌉ seekers inspect ports in parallel. Even a vertex of degree n − 1 needs at most three probe batches.

Worked example · Algorithm 2

Choose red when no neighbour is red.

The seekers colour the root red, then inspect each new vertex in depth-first order. A red neighbour makes the new vertex blue. Otherwise it joins the red set.

On this five-vertex star, a leaf root selects all four leaves. A centre root selects just the centre. Both sets are inclusion-minimal.

Correctness · Theorem 3.4

Every selected vertex is indispensable.

Domination

A blue vertex was coloured only after a seeker found a red neighbour. Red vertices keep their colour, so that neighbour still covers it at termination.

Minimality

Two adjacent vertices cannot both be red. The later one would see the earlier one. Removing any red vertex therefore leaves that vertex itself undominated.

Make the virtual colours permanent

During a final tree traversal, seekers occupy the remaining vacant vertices and inherit their recorded colours. Each of the n agents now stores the membership of one vertex.

Arbitrary start · Algorithms 3–6

Turn many starting points into one root.

Disperse and detect completion

Clusters grow depth-first trees. A singleton uses its ID bits to alternate between waiting and visiting a fixed port. Trees probe for edges leading outside their component and merge when they meet.

Elect and gather

Once the surviving tree finishes its search for an external edge, its root becomes leader. Agents store tree pointers, finalise dispersion and gather from leaves upward. Each internal agent waits for all child groups before moving to its parent.

Run the rooted construction

All agents are together at the leader. They can now build the covered configuration, colour the graph and settle the seekers using Algorithm 2.

Complexity · Theorems 3.4, 4.7 and 4.9

Why the time bound is linear

O(n)

synchronous rounds

The rooted procedure uses a constant number of tree traversals. A bounded number of probe batches and a bounded wait at each covered vertex keep the colouring cost constant per visit.

O(log n)

bits per agent

An agent stores its ID, a bounded number of tree ports and local state. An oscillating explorer carries colour records for only a constant number of vertices.

For an arbitrary start, the paper also bounds dispersion with termination detection, leader election, tree construction and gathering by O(n) rounds in total.

Approximate minimum dominating set · Section 5

To control the size, change the selection rule.

Count the gain

A vertex’s span counts the still-undominated vertices it could cover, including itself. A candidate compares spans within two hops, breaking ties consistently by ID.

Choose how to communicate

The leader learns n, maximum degree Δ and maximum ID λ. It chooses between repeated neighbour meetings and four seeker traversals per greedy phase.

The size guarantee

The charging proof bounds the output size by HΔ+1 times optimum, where Hk = 1 + ½ + … + 1/k. This gives the paper’s logarithmic approximation.

O(min{n², nΔ log λ}) rounds

Memory remains O(log n) bits per agent.
